# Secure File Hider

A Java and MySQL-based application for securely hiding and managing files with user authentication and security features. The project includes login authentication, OTP generation, email verification, encryption, and MySQL database integration.

## Tech Stack
- Java
- MySQL
- Maven
- Encryption
- OTP & Email Authentication

## Features
- User login and authentication
- OTP generation and verification
- Email-based authentication
- File hiding and management
- Encryption for protecting files
- MySQL database integration

## Project Structure
The application is organized into separate modules for Views, Services, DAO, Models, and Database connectivity.

## How to Run
1. Configure the MySQL database connection.
2. Open the project in a Java IDE.
3. Build the project using Maven.
4. Run `Main.java`.

## Learning Outcomes
This project provided practical experience in Java, database integration, authentication, OTP verification, encryption, file handling, and structured application development.
